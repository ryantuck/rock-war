ROCK WAR [Fibonacci Variant]

Rock War is a simple game designed to be played using an arbitrary map and an arbitrary number of rocks, doodads, or trinkets you have lying around.

Armies wage war in an all-out battle royale via territorial expansion, combat, and the elemental magic of the obelisks.


----------------------------------------------

How to Play

1. Design - select map, armies, and obelisks
2. Placement - place obelisks, then place two scouts each, snake-style
3. Gameplay - each contingent pays up to N for further ramp, movement, and combat
4. End-game - game ends when one army can do nothing else

1. MAP

A map is an arbitrary graph of territories. It can be a grid, a honeycomb like Settlers, or a realistic map like Risk.


MAP / Territories

Only one army can occupy any given territory


MAP / TERRITORIES / CAPACITY

Each territory supports 1, 2, 3, 5, or 8 total value.


MAP / TERRITORIES / ELEVATION

- Some territories are elevated
- Elevated territories cost an additional movement to access
- Warriors attacking from above get +1 attack

----------------------------------------------

2. ARMIES

Each Rock War battle is between two or more armies.

ARMIES / PIECES

    - 8x scouts     (1 pt )
    - 5x soldiers   (2 pts)
    - 3x chieftains (3 pts)
    - 2x warlords   (5 pts)
    - 1x behemoth   (8 pts)

ARMIES / PIECES / EVOLUTION

    Pieces evolve into one another according to the Fibonacci sequence
    Pieces must occupy the same territory to evolve

----------------------------------------------


3. OBELISKS

Obelisks are the core abilities engine of the game.


Obelisk / Abilities

  Devolve
  Return
  Sacrifice

Obelisks / Devotion

  Devotion - measure of how many territories you occupy surrounding an obelisk
  Full devotion - effects are intensified if you control all territories surrounding an obelisk

Obelisks / Affinities

  Smooth army - affinity for water and air
  Rough army - affinity for earth and fire


----------------------------------------------

5. PLACEMENT

At the beginning of the game, each army places two scouts anywhere on the board, in snake style.

----------------------------------------------

7. RAMP

The total number of territories you control defines your ramp.

Default: ramp 1
5+ territories: ramp 2
8+ territories: ramp 3


----------------------------------------------

8. MOVEMENT

- Each piece may move once per turn
- Only scouts may move into open territory
- All territories must contain valid rock combinations (e.g. 2+3) after every movement
