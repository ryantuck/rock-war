ROCK WAR [Fibonacci Variant]

Rock War is a simple game designed to be played using an arbitrary map and an arbitrary number
of rocks, doodads, or trinkets you have lying around.

Armies wage war in an all-out battle royale via territorial expansion, combat, and the elemental
magic of the obelisks.

----------------------------------------------

How to Play

1. Setup 	Select map, armies, and obelisks, and place initial rocks
2. Play		Armies alternate moving, evolving, attacking, and spawning
3. Win		Game ends when one army can do nothing else

MECHANICS

MECHANICS / PLACEMENT

    At the beginning of the game, each army places two scouts anywhere on the board,
    in snake style.


MECHANICS / TURNS

    Armies alternate turns moving, evolving, attacking, and spawning.

    MV:     Move                N territories               1 - 20
    EV:     Evolve              N rock types                1 - 5
    ATK:    Attack              Maximum warrior strength    2, 3, 5, 8
    RAMP:   Ramp                1 + N obelisks              1 - 6
    OB:     Trigger obelisk     N obelisks                  1 - 5


MECHANICS / TURNS / SEQUENCE

        My Army         Opponent        Location


MAIN    Move                            Map
        Evolve
        Obelisks        Obelisks

COMBAT  Attack          Retreat
                        Defend          Map -> Graveyard
        Revive          Revive

SPAWN   Ramp                            Reserves -> Map


MECHANICS / EVOLUTION

    Pieces evolve into one another according to the Fibonacci sequence

    Pieces must occupy the same territory to evolve

    [1] [1] ==> [2]
    [1] [2] ==> [3]
    [2] [3] ==> [5]
    [3] [5] ==> [8]


MECHANICS / MOVEMENT

    Only scouts may move into open territory








----------------------------------------------

MAP

    A map is an arbitrary graph of territories.

    It can be a grid, a honeycomb like Settlers, or a realistic map like Risk.


MAP / TERRITORIES

    Only one army can occupy any given territory.


MAP / TERRITORIES / CAPACITY

    Each territory supports 1, 2, 3, 5, or 8 total value.

    All territories must contain valid rock combinations (e.g. 2+3) after every movement


MAP / TERRITORIES / ELEVATION

    Some territories are elevated

    Elevated territories cost an additional movement to access

    Warriors attacking from above get +1 attack


----------------------------------------------

ARMIES

    Each Rock War battle is between two or more armies.

ARMIES / PIECES

    8x scouts     (1 pt )
    5x soldiers   (2 pts)
    3x chieftains (3 pts)
    2x warlords   (5 pts)
    1x behemoth   (8 pts)


----------------------------------------------

COMBAT

    One or more warriors attack into a single target territory.

    Blockers decide how to apply blocks. Blocks are applied one at a time.

    Attacker decides to continue attacking.

    Combat rules are applied recursively as pieces devolve in combat.

    [2-] = weakened [2] = effectively []









COMBAT / Battle Tables


    []  -> o        ==>                             Scouts trade
    [2] -> (2)      ==>     [][]->oo                Equal values - both pieces devolve
    [3] -> (3)      ==>     [2-][] -> (2-)o
    [5] -> (5)      ==>     [3-][2-] -> (3-)(2-)
    [8] -> (8)      ==>     [5-][3-] -> (5-)(3-)

    [2] -> o        ==>     [][]
    [3] -> o        ==>     [3]
    [5] -> o        ==>     [5]
    [8] -> o        ==>     [8]

    [3] -> (2)      ==>     [2-][]      Stronger piece devolves, weaker destroyed
    [5] -> (2)      ==>     [5]
    [8] -> (2)      ==>     [8]

    [5] -> (3)      ==>     [3-][2-]
    [8] -> (3)      ==>     [8]

    [8] -> (5)      ==>     [5-][3-]


    [2] -> oo       ==>     []          [2]->oo => [][]->o => __->[]
    [3] -> oo       ==>     [3]
    [5] -> oo       ==>     [5]
    [8] -> oo       ==>     [8]

    [3] -> (2)o     ==>     [][]


COMBAT / Battle Tables / Further Examples


[3][2]  -> (3)      ==>     [2][][][] or [3]

    either:

        [3]->(3)    ==> [2-][] (2-)o    (3) block [3], both devolve
        [2]->(2-)o  ==> [][]            [2] attack weakened (2-)o, equivalent to [2]->oo
                    ==> [2][][][]       Victor distributes valid combos among combat territories

    or:

        [2]->(3)    ==> (2-)o           (3) block [2], defending (3) devolves, attacker destroyed
        [3]->(2-)o  ==> [3]             [3] attacks weakened (2-)o, equivalent to [3]->oo
                    ==> [3]             Victor claims target territory



[8] -> (5)(3)

    [8] -> (5)      ==>  [5-] -> (3)    ==>     [2-] -> (2-)    ==>

                                                [3-] -> o               [2-][]
                                                [2-]                    [2-]

                                        ==>     [3-] -> (2-)    ==>     [2-][]
                                                [2-] -> o
                                                [3-]                    [3-]


                    ==> [3-] -> (3)     ==>     [5-] -> (2-)    ==>     [5-] -> o   ==>     [5-]
                        [5-]                             o

OBELISKS

    Obelisks are the core abilities engine of Rock War.

EARTH
-----

Devotion

    Fertility           RAMP++
    Shelter             DEF++

Devolve

    Pacifism            Target warrior X can't attack next turn
    ATK--               Reduce attack count by 1
    Pump                Pump target blocking warrior

Return

    Double Block        Target defending warrior blocks twice before receiving damage
    Reinforcements      Adjacent warrior X or below joins defense in combat
    Indestructible      Target blocking rock is indestructible this turn
    Tremor              Evenly split up one territory of value X into all its available
                          adjacent territories

Sacrifice

    Evolve              Evolve up to X
    Landslide           Deal X damage among 2+ adjacent territories (?)
    Earthquake          Radiate outwards,
                          shift pieces into adjacent territories,
                          proportional damage
